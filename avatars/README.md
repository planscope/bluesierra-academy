# Sierra Crew avatars

`crew.json` holds the parts the portal uses to draw everyone's character (the browser puts them together and caches each face).

- Faces, hair, eyes, brows, noses, mouths, beards, glasses and outfits: **Notionists** by Zoish, CC0 1.0 (public domain). https://heyzoish.gumroad.com/l/notionists
- Hard hat, cowboy hat and hi-vis safety vest: drawn for Blue Sierra.

A saved character looks like `sc:h=30;x=hard;v=1;y=14;e=02;b=09;n=15;l=14;g=;d=;c=6`
(h hair, x hat: cap / hard / cowboy, v vest, y outfit, e eyes, b brows, n nose, l mouth, g glasses, d beard, c background color).
